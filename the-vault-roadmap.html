Config gatePhase 03. The taxonomy, the ownership and the accepted sources come from Sharizal's price file and must be confirmed by him. Nothing downstream is final until the first configuration is validated.
GO gatePhase 04. The stakeholder demo converts the prototype into a mandate. No development starts before it. The design language is frozen so this gate is about scope and value, not aesthetics.
